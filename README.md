# Tokyo 2026 Interactive Trip

這個資料夾可直接上傳到 GitHub Pages。

## 上傳方式
1. 在 GitHub 建立新的 repository，例如 `tokyo-trip`
2. 上傳此資料夾內的：
   - `index.html`
   - `.nojekyll`
3. 到 Settings → Pages
4. Build and deployment 選擇 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/ (root)`，按 Save
6. 等待 GitHub Pages 產生網址

網站首頁會自動使用 `index.html`。
